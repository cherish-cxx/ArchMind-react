四种视觉语言，共用一个产品骨架

当前界面的信息架构是清楚的：状态对应下一步动作、继续上次、会话按项目分组、画布与对话同屏。 需要换掉的是视觉语言：主色、字阶、圆角、阴影、卡片层级，以及画布上过多的编码。 下面四个方向都能承接现有功能，但气质、阅读负担和维护成本不同。

现状：不是“不好看”，是系统没有建立

怎么选

方向气质最适合代价
A 测绘图 冷静、精确、像工具 让画布成为绝对主角；代码架构产品的辨识度最高 偏冷；画布节点与连线需要重新打磨，否则会显得简陋
B 夜航图 沉浸、空间感、有记忆点 演示与长时间看图；暗色环境；想让产品“看起来不一样” 中文长文在深色底上更累；需要额外设计一套日光模式
C 批注 安静、可读、像研究笔记 讲解与引用是核心；用户主要在读 Agent 的结论 画布会被降级为辅助；荧光色控制不好会显得廉价
D 静默仪器 克制、通用、产品化 先稳妥升级，不改变现有使用习惯 辨识度最低；和现在的差距最小

无论选哪个，都要先做的四件事

现在的问题不只是“配色不好看”，而是颜色、字号和形状没有形成系统。 先把地基换掉，再套方向，才不会出现“新皮肤 + 旧补丁”的混合状态。

语义色层

把 77 个变量收敛成 surface / ink / line / accent / state / relation / kind 七组；主色不再和画布节点蓝各说各话。

字阶与对比度

17 种字号收敛到 6 级；10–11.5px 的说明文字升到 12px 以上；text-3、text-4 达到 4.5:1。

形状与层级

圆角、阴影、胶囊各保留一套；页面内元素不投影，只有浮层允许 elevation。

深色与动效

深色从同一套语义变量推导，不再逐选择器覆盖；全局尊重 reduced-motion，焦点环统一。

样张只用于比较方向，未改动应用代码。选定方向后，建议先落地 token 层 + 工作台/记忆地图两个页面，再铺到其余界面。
